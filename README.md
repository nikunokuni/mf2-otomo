# モンファーのおとも

モンスターファーム2の **技の使い込み** と **育成計算** を、ひとつのアプリにまとめたものです。
ビルド不要の静的サイトなので、GitHub Pages にそのまま置けます。

## できること

### モンスタータブ

そのモンスター1体について、ゲーム側で決まっている値をまとめて置く場所です。
ここに入れた値を、使い込みタブと育成計算タブが読んで動きます。

- 全38種族から選んで追加。選んだ種族はタブバーの下にチップで並び、押すと切り替わる
- 成長タイプ / ヨイワル / 寿命 / 成長適正（6種）/ 初期パラメーター（6種）
- ガッツ回復速度（使い込みタブの理想回数に使う）
- エサの好き嫌い（6種を 好き / 普通 / 嫌い。調整ローテのエサの効き方に使う）

### 使い込みタブ

- 全38種族の使い込み技データを収録
- 大会ごとの使い込み回数を記録し、合格で累計に加算 / やり直しで破棄
- モンスタータブのガッツ回復速度から「理想使用回数」（命中時・空振り時）を自動計算
- 技の選択を外しても、その技の記録は残る
- 種族ごとのメモと履歴

### 育成計算タブ

「育成計画 / 調整ローテ / 結果」の3つに分かれています。
寿命・成長タイプ・成長適正・初期パラメーターはモンスタータブ側で入れます。

#### 育成計画（全期間をざっくり組む）

- 寿命と成長タイプから、成長段階ごとの週数を自動で割り出す
- 段階ごとに重トレ / 軽トレ / イベントを組んで、最終パラメーターを試算
  （イベントで減る寿命は 大会-4週 / 修行-7週 / 冒険-2週）
- 各段階が始まる時期を「○月◎週」で表示。イベントの「減る寿命と進む週数の違い」も
  織り込むので、計画と実際の暦が合う
- 寿命が減るアイテム（パラドクシンなど）の回数も段階ごとに入れられる。
  割当週を超えたぶんは、次の段階の週数から自動で引く
- 選んだトレーニングの1回ぶんの上昇値を、その場（トレーニング欄の下）に色分けで表示
  （重トレは計算に使っている値、軽トレは上がりうる最大値）
- 桃システム（黄金桃 +50週 / 白銀桃 +25週）による若返りぶんも計算
- 1つの段階を複数のセットに分けて、途中で方針を変える計画も組める
- 上昇値に効く成長適正を、表の上に読み取り専用で small 表示（書き換えはモンスタータブ）

#### 調整ローテ（短い期間を1週ずつ組む）

育成計画の短期詳細版。1週ずつアイテムと行動を並べて内部数値を追う画面です。

- 調整ローテを始める時点の内部数値（体型・ヨイワル・ストレス・疲労・恐れ度・甘え度）と、
  双子の水差しの所持数を入力。ヨイワルはモンスタータブの初期ヨイワルから±100までしか
  動かないので、その範囲に収めます
- エサ6種の効き方を、そのモンスターの好き嫌いを当てはめて一覧表示
  （ストレス・恐れ度・甘え度は好き嫌いで変わり、体型と買値は変わりません）
- 1週ずつアイテムと行動を入力。**1週ぶん入れると次の週の欄が出てきます（上限なし）**。
  月初め（第1週）の行では、その月のエサも選べます
- 各週の下に、その週が終わった時点の内部数値を帯で表示。
  1週のなかの順番は「月初めなら エサ → 双子の水差し、そのあと アイテム → 行動」
- 行動は 軽トレ / 重トレ / 休養 / 大会（優勝・他・ビリ）/ 修行 / 冒険。
  休養は成長段階で効き方が変わるので、段階もここで選びます。
  大会は疲労がそのときの体型で決まり、そのあとストレスは0になります
- **修行と冒険は4週まとめて出かけます。** 選ぶと4週ぶんが埋まります。
  出かける週にはエサが間に合い（冒険はアイテムだけ使えません）、2〜4週目は
  エサもアイテムもありません。帰ってきた週からはふつうに戻ります。
  修行は疲労とストレスが毎週たまり、冒険は何も起きずに疲労+70 が帰ってきた週に乗ります
- **体調値（＝疲労＋ストレス×2）と、その週に減る寿命**を各週に表示。下に合計も出します。
  寿命は「**週経過ぶん**（1週たてば-1。暦も進む）＋ **追加ぶん**（暦は進まない）」の2本立てで、
  追加ぶんは**体調値ぶんとイベントぶんの両方**がかかります。
  体調値の表は週経過ぶんを含んだ合計なので、**体調値69以下なら追加ぶんはありません**。
  大会は出場で-3（大会後の疲労が70を越えるとその倍の-6）、冒険は-2、修行そのものの追加はなし。
  疲労0・ストレス0から始めた場合、大会-4 / 修行-7 / 冒険-2 となり
  育成計画の `EV_COST` とぴったり合います

### 早見タブ

育成中にさっと確認したい情報を、箱に並べて表示します。
箱の高さは固定で、あふれた中身は箱の中だけがスクロールします（リンク集だけは中身に合わせて伸びます）。

ここの中身はどれも種族に関係しないので、早見タブでは種族チップの帯も出しません。

- **ローテ / 合体素材** … アプリ側のデータを表示（中身は `js/data/reference-data.js` に書く）
- **アイテム** … 収録ぶん（`js/data/items.js`。読むだけ）のうしろに、自分で足したぶんが並ぶ。
  足す・直す・消すのもここ。種族に関係なく共通で持つ
- **再生メモ** … モンスター・タイトル・歌手・自由メモを自分で記録（種族とは別に、まとめて保存）
- **リンク集** … あらかじめ入れた3つに加えて、名前とURLを自分で追加できる。名前がそのままボタンになり、押すと別タブで開く
- **データのバックアップ** … JSONの書き出しと読み込み

### 共通

- **種族の選択はタブバーの下のチップ帯で共有**（モンスター / 使い込み / 育成計算 で同じ種族を見る）
- 入力は自動でブラウザに保存。開いていたタブも覚える
- PWA対応（ホーム画面に追加、オフラインでも動く）
- ライト / ダークの自動切替
- データのJSON書き出し・読み込み

## 開発するときに気をつけること

- **種族名・技名・エサ名は保存データのキー**です。表記を1文字でも変えると、
  その種族・技・エサの記録が読めなくなります。
- **ファイルを増やしたら `sw.js` の `ASSETS` に追加**し、`CACHE_VERSION` を上げてください。忘れるとオフラインで読み込めません。
- **インラインの `onclick` は使いません。** 要素に `data-action` / `data-change` / `data-input` を書き、
  `js/main.js` でハンドラを登録します（`js/dom.js` がイベント委譲でまとめて受け取ります）。
- **色は必ず `css/tokens.css` の変数を経由**してください。直接 `#ffffff` などを書くと、ダークモードで読めなくなります。
- 計算ロジックは画面から切り離してあるので、`growth-calc.js` と `ideal.js` は Node だけでテストできます。
- **置き場の決め方**は2つの軸で決めています。迷ったらこれに合わせてください。
  - *そのデータは種族ごとか、全体で1つか* … 種族ごとならモンスター/使い込み/育成計算のどれか。
    全体で1つなら早見タブ（早見タブでは種族チップの帯も隠しています）。
  - *個体の決まった値か、そのつど組むものか* … 決まった値はモンスタータブ。
    組むものは育成計算タブ。
- モンスタータブで直した値は、上位タブを開き直したときに `js/main.js` の `onTopShown` が
  該当タブを描き直して反映しています。

## テスト

```bash
npm install          # playwright を入れる（開発時のみ）
npm test             # 計算 + 画面 + 移行 をまとめて実行
```

画面のテストはローカルサーバーを立てて実行します。

```bash
python3 -m http.server 8811
```

## 公開のしかた

1. リポジトリを GitHub にpush
2. Settings → Pages → Source: `main` ブランチ、`/ (root)` を選択
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 以前のアプリからの移行

このアプリを開くと、以前の「使い込みトラッカー」の記録
（`localStorage` の `mf2_mf2v8_state`）を自動で引き継ぎます。
同じ `github.io` のドメインで公開していれば、URLが変わっても記録は残ります。

引き継ぎ後も元のデータは消さずに残しているので、以前のアプリもそのまま使えます。

## データについて

技データは有志Wikiを参照して作成しています。
ガッツ回復速度は「30ガッツ回復にかかる秒数」で入力してください（6〜19）。

なお、モンスタータブの **ヨイワル（-100〜100、5きざみ）は、現時点では計算結果に
反映されません**。記録用の入力欄として残してあります。
育成計画の **開始時期（月・週）** は、段階が始まる時期（○月◎週）の計算に使っています。
