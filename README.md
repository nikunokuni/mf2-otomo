# モンファーのおとも

モンスターファーム2の **技の使い込み** と **育成計算** を、ひとつのアプリにまとめたものです。
ビルド不要の静的サイトなので、GitHub Pages にそのまま置けます。

## できること

### 使い込みタブ

- 全38種族の使い込み技データを収録
- 大会ごとの使い込み回数を記録し、合格で累計に加算 / やり直しで破棄
- ガッツ回復速度から「理想使用回数」（命中時・空振り時）を自動計算
- 技の選択を外しても、その技の記録は残る
- 種族ごとのメモと履歴

### 育成計算タブ

- 寿命と成長タイプから、成長段階ごとの週数を自動で割り出す
- 段階ごとに重トレ / 軽トレ / イベントを組んで、最終パラメーターを試算
  （イベントで減る寿命は 大会-4週 / 修行-7週 / 冒険-2週）
- 各段階が始まる時期を「○月◎週」で表示（開始時期と段階の週数から計算。桃のぶんも織り込む）
- 選んだトレーニングの1回ぶんの上昇値を、その場（トレーニング欄の下）に色分けで表示
  （重トレは計算に使っている値、軽トレは上がりうる最大値）
- 桃システム（黄金桃 +50週 / 白銀桃 +25週）による若返りぶんも計算
- 1つの段階を複数のセットに分けて、途中で方針を変える計画も組める
- 「アイテム」でアイテムの名前と効果を確認・追記（収録ぶんは `js/data/items.js`。
  足したぶんは種族に関係なく共通で、早見タブのアイテムにも出る）

### 早見タブ

育成中にさっと確認したい情報を、箱に並べて表示します。
箱の高さは固定で、あふれた中身は箱の中だけがスクロールします（リンク集だけは中身に合わせて伸びます）。

- **ローテ / アイテム / 合体素材** … アプリ側のデータを表示（中身は `js/data/reference-data.js` に書く）。
  アイテムは、育成計算タブの「アイテム」で入れたぶんも続けて並びます
- **再生メモ** … モンスター・タイトル・歌手・自由メモを自分で記録（種族とは別に、まとめて保存）
- **リンク集** … あらかじめ入れた3つに加えて、名前とURLを自分で追加できる。名前がそのままボタンになり、押すと別タブで開く

### 共通

- **種族の選択は両タブで共有**（使い込みで選んだ種族が、そのまま育成計算の対象になる）
- 入力は自動でブラウザに保存。開いていたタブも覚える
- PWA対応（ホーム画面に追加、オフラインでも動く）
- ライト / ダークの自動切替
- データのJSON書き出し・読み込み

```

sw.js                 Service Worker（オフライン対応）
assets/               アイコン

  tokens.css          色・角丸・フォントの定義（配色を変えるならここだけ）
  base.css            リセットと土台
  components.css      ボタン・カード・タブなど共通部品
  tracker.css         使い込みタブ固有
  simulator.css       育成計算タブ固有
  reference.css       早見タブ固有（箱の高さは --ref-box-height）

js/
  main.js             起動処理。操作の登録はすべてここに集約
  store.js            状態と localStorage への保存、旧データからの移行
  dom.js              DOMヘルパーとイベント委譲
  tabs.js             2階層タブの制御（上位: 使い込み/育成計算/早見）
  species.js          種族の選択（両タブ共有）
  data/
    growth.js         育成計算の定数テーブル
    monsters.js       38種族の使い込み技データ
    items.js          アイテムデータ（効果は数値でも持つ）と内部数値の範囲
    icons.js          種族アイコン（約40KB / 遅延読み込み）
    reference-data.js 早見タブに出す内容（ローテ・アイテム・合体素材）
  tracker/
    tracker.js        使い込みタブの画面
    ideal.js          理想使用回数の計算
  simulator/
    simulator.js      育成計算タブの画面
    growth-calc.js    育成計算のロジック（画面に依存しない）
    inner-calc.js     内部数値の範囲と割合の切り捨て（画面に依存しない）
    items.js          育成計算タブ「アイテム」の入力画面
  reference/
    reference.js      早見タブの画面（箱の並びと再生メモ・リンク集の入力）

test/
  calc.test.mjs       計算ロジックの検証
  app.test.mjs        画面操作の検証
  migration.test.mjs  旧データ移行・バックアップ・オフラインの検証

docs/
  roadmap.md          今後の開発案（まだ着手していないもののメモ）
```

## 開発するときに気をつけること

- **種族名と技名は保存データのキー**です。表記を1文字でも変えると、その種族・技の記録が読めなくなります。
- **ファイルを増やしたら `sw.js` の `ASSETS` に追加**し、`CACHE_VERSION` を上げてください。忘れるとオフラインで読み込めません。
- **インラインの `onclick` は使いません。** 要素に `data-action` / `data-change` / `data-input` を書き、
  `js/main.js` でハンドラを登録します（`js/dom.js` がイベント委譲でまとめて受け取ります）。
- **色は必ず `css/tokens.css` の変数を経由**してください。直接 `#ffffff` などを書くと、ダークモードで読めなくなります。
- 計算ロジックは画面から切り離してあるので、`growth-calc.js` と `ideal.js` は Node だけでテストできます。

## テスト

```bash
npm install          # playwright を入れる（開発時のみ）
npm test             # 計算 + 画面 + 移行 をまとめて実行
```

画面のテストはローカルサーバーを立てて実行します。

```bash
python3 -m http.server 8811
```

## 公開のしかた

1. リポジトリを GitHub にpush
2. Settings → Pages → Source: `main` ブランチ、`/ (root)` を選択
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 以前のアプリからの移行

このアプリを開くと、以前の「使い込みトラッカー」の記録
（`localStorage` の `mf2_mf2v8_state`）を自動で引き継ぎます。
同じ `github.io` のドメインで公開していれば、URLが変わっても記録は残ります。

引き継ぎ後も元のデータは消さずに残しているので、以前のアプリもそのまま使えます。

## データについて

技データは有志Wikiを参照して作成しています。
ガッツ回復速度は「30ガッツ回復にかかる秒数」で入力してください（6〜19）。

なお、育成計算タブの **開始時期（月・週）とヨイワル（-100〜100、5きざみ）は、
現時点では計算結果に反映されません**。記録用の入力欄として残してあります。
